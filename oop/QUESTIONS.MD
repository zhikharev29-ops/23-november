# Контрольные вопросы

## 1. Чем класс отличается от объекта?
Класс — это шаблон (чертёж): он описывает, какие данные хранит сущность и что умеет делать. Объект — конкретный экземпляр, созданный по этому шаблону оператором `new`. Класс `Car` один, а объектов может быть много (`$car1`, `$car2`), и у каждого свои значения свойств.

## 2. Для чего нужен конструктор и когда он вызывается?
Конструктор `__construct()` задаёт начальное состояние объекта: принимает параметры и заполняет свойства (при необходимости проверяет данные и выбрасывает исключение). PHP вызывает его автоматически в момент создания объекта через `new`, вручную его вызывать не нужно.

## 3. Что означает $this и почему он недоступен в статических методах?
`$this` — ссылка на текущий объект внутри его методов, через неё метод обращается к свойствам и другим методам этого объекта. Статический метод принадлежит классу и вызывается без создания объекта (`Calculator::square(4)`), поэтому «текущего объекта» в нём нет, и `$this` использовать нельзя. Из статического метода доступны только статические члены (`self::`, `static::`).

## 4. Чем отличается $obj2 = $obj1 от $obj2 = clone $obj1?
При `$obj2 = $obj1` копируется только ссылка (идентификатор) на объект: обе переменные указывают на один и тот же объект, изменение через одну видно через другую. `clone $obj1` создаёт новый независимый объект с теми же значениями свойств. В практической работе 1 это видно: после изменения названия у `$b1` книга `$b2` изменилась, а `$b3` (клон) нет.

## 5. Чем статическое свойство отличается от обычного? Как к нему обратиться?
Обычное свойство принадлежит каждому объекту отдельно. Статическое (`static`) принадлежит классу и общее для всех объектов: изменили в одном месте, изменилось для всех. Обращаются к нему через класс: `Student::$totalStudents` или `self::$totalStudents` внутри класса. Константа класса (`const`) — тоже общая, но неизменяемая: `Student::MAX_COURSE`.

## 6. Что такое readonly-свойство и когда его можно присвоить?
`readonly` (PHP 8.1) — свойство, которое можно записать только один раз, обычно в конструкторе, и только из области видимости самого класса. После этого любая попытка изменения приводит к `Error: Cannot modify readonly property`. Свойство должно иметь тип. Пример из работы: `public readonly int $id` у студента.

## 7. Что такое продвижение свойств в конструкторе?
Это возможность PHP 8.0 объявлять и заполнять свойства прямо в списке параметров конструктора: `__construct(private string $name)`. Модификатор доступа перед параметром превращает его в свойство класса, и присваивание `$this->name = $name` писать не нужно. Код становится короче.

## 8. Как реализовать цепочку вызовов методов?
Каждый метод в конце делает `return $this;` и указывает тип возврата `static` (или `self`). Тогда результат вызова — снова тот же объект, и можно писать `$calc->add(5)->multiply(3)->add(1)`. Так устроен `QueryBuilder` в практической работе 4.

## 9. Назовите три магических метода и случаи, когда PHP их вызывает.
- `__construct()` — при создании объекта через `new`.
- `__toString()` — когда объект используют как строку, например `echo $obj`.
- `__set()` — при записи в недоступное или несуществующее свойство; `__get()` — при чтении такого свойства.
- `__call()` — при вызове недоступного или несуществующего метода (в работе 4 так сделаны `whereCity()` и подобные).
- `__destruct()` — когда объект уничтожается.

## 10. Чем protected отличается от private при наследовании?
`private` доступен только внутри самого класса: наследник его не видит (в наследнике чтение такого свойства даёт предупреждение «Undefined property»). `protected` доступен и внутри класса, и в классах-наследниках, но снаружи (`$obj->...`) закрыт. Поэтому `baseSalary` сделан `protected`, чтобы `Manager` и `Developer` могли считать зарплату, а `passport` — `private`.

## 11. Что делает ключевое слово final?
`final` у метода запрещает переопределять его в наследниках, `final` у класса запрещает от него наследоваться. При попытке переопределить такой метод PHP выдаёт Fatal error: `Cannot override final method Employee::getMaskedPassport()`.

## 12. Как работает spl_autoload_register?
Функция регистрирует загрузчик — функцию, которую PHP вызывает автоматически, когда встречает класс, который ещё не объявлен (`new`, статический вызов, `instanceof` с загрузкой и т. д.). Загрузчик получает полное имя класса вместе с пространством имён, находит нужный файл и подключает его через `require`. Так классы загружаются только в момент первого использования, а ручные `require` для каждого класса не нужны. Можно зарегистрировать несколько загрузчиков, они вызываются по очереди.

## 13. Как стандарт PSR-4 связывает пространство имён и путь к файлу?
Префикс пространства имён сопоставляется базовой папке (например, `Shop\` → `src/`). Остальная часть имени класса превращается в путь: обратные слэши заменяются на `/`, в конце добавляется `.php`. Класс `Shop\Models\Product` лежит в `src/Models/Product.php`. Имя файла совпадает с именем класса, в одном файле один класс.

## 14. Когда нужно выполнять composer dump-autoload?
Когда меняется конфигурация автозагрузки в `composer.json` (добавлен или изменён префикс в `psr-4`, добавлены `classmap` или `files`), а также после первого создания `composer.json` с секцией `autoload`. Для обычных новых классов внутри уже сопоставленной папки PSR-4 команда не нужна: Composer ищет файл по пути в момент загрузки. Она нужна и при использовании оптимизированного автозагрузчика (`-o`), где все классы заранее записаны в карту.
